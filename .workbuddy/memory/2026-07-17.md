# 2026-07-17 Work Log

## Instagram API Fix (CRITICAL)

**Problem:** The live site's `/api/events/instagram` endpoint was returning `{"body":[]}` (zero events) on Vercel, despite having data locally. Users could only see Google Calendar and Eventbrite events — all Instagram-sourced events were missing.

**Two root causes found and fixed:**

### 1. `useStorage()` fails on Vercel serverless
- The endpoint used `useStorage().getItem('assets:server:instagram_data.json')` which works in dev but returns `null` on Vercel
- **Fix:** Changed to direct `import instagramData from '../../assets/instagram_data.json'` — data is now bundled into the endpoint's server chunk at build time (2.6MB), guaranteeing availability at runtime
- File: `server/api/events/instagram.ts`

### 2. Instagram data was wiped to `[]` by failed scraper runs
- GitHub Actions daily cron was running until June 15, but the scraper was failing (likely DeepSeek API issues)
- The script wrote `[]` to `server/assets/instagram_data.json` and the auto-commit pushed the empty file
- **Fix:** Restored data from git commit `66ffb09` (May 22) — 43 sources, 1,044 events, 147 upcoming after July 17

**Commits pushed:**
- `a7d0187` — fix: Instagram API returns empty on Vercel (direct import)
- `88d484b` — fix: restore Instagram event data

**Verified:** Live API at `https://www.triad.build/api/events/instagram` now returns 43 sources with events.
